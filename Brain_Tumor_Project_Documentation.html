1. Project Overview & Objectives

This project presents a comprehensive end-to-end deep learning and evolutionary optimisation framework for automated brain tumor detection and multi-class classification from Magnetic Resonance Imaging (MRI) scans. The system combines convolutional deep feature extraction via transfer learning, a Genetic Algorithm (GA) for intelligent feature selection, and a benchmarked suite of machine learning classifiers, packaged in a real-time interactive Streamlit web application.

Objectives

  • Automatically detect and classify brain tumors from raw MRI scans into four diagnostic classes.
  • Apply clinically relevant image preprocessing (CLAHE, denoising, normalization) to enhance feature quality.
  • Extract rich semantic features from pretrained EfficientNetB0 through fine-tuned transfer learning.
  • Reduce the 1,280-dimensional feature space using a Binary Genetic Algorithm, removing redundant features while preserving accuracy.
  • Train, tune, and benchmark four classifiers (Softmax, SVM, Random Forest, XGBoost) using cross-validated hyperparameter search.
  • Deploy an interactive inference web app enabling real-time MRI diagnosis with visual explainability.

Tumor Classification Classes

Glioma

Arises from glial cells in the brain and spinal cord. Among the most common and aggressive primary brain tumors.

Meningioma

Tumor arising from the meninges (brain membranes). Usually benign but can compress adjacent brain tissue.

Pituitary

Tumor in the pituitary gland at the brain base. Often benign but can disrupt hormone regulation.

No Tumor

Healthy MRI scan with no observable tumor mass — the negative class in the 4-way diagnostic classification.

4. Pipeline Stages — Technical Details

4.1 Stage 1 & 2 — Data Download & Preprocessing

Modules: src/dataset_setup.py & src/preprocessing.py

Image Preprocessing Pipeline

Each raw MRI image is processed through the following sequential steps via preprocess_single_image():

  1. Grayscale Conversion — MRI images are read/converted to single-channel grayscale.
  2. Resize — All images resized to 224 × 224 px using cv2.INTER_AREA interpolation (optimal for downsampling).
  3. Median Filter Denoising — A 3×3 median blur kernel suppresses salt-and-pepper noise while preserving edges.
  4. CLAHE Enhancement — Contrast Limited Adaptive Histogram Equalization (clipLimit=2.0, tileGridSize=(8,8)) enhances local contrast in tumor regions.
  5. Min-Max Normalization — Pixel values scaled to [0.0, 1.0] float32.
  6. 3-Channel Conversion — Grayscale stacked to 3-channel BGR for EfficientNetB0 compatibility.
Why CLAHE? Standard histogram equalization applies a global transformation, washing out subtle tumor boundaries. CLAHE applies localized enhancement tile-by-tile, making tumor regions more distinguishable without over-amplifying background noise. 
img_resized  = cv2.resize(img, (224,224), interpolation=cv2.INTER_AREA)
img_denoised = cv2.medianBlur(img_resized, 3)
clahe        = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))
img_clahe    = clahe.apply(img_denoised)
img_norm     = img_clahe.astype(np.float32) / 255.0     # Normalize to [0,1]
img_bgr      = cv2.cvtColor((img_norm*255).astype(np.uint8), cv2.COLOR_GRAY2BGR)

4.2 Stage 3 — Tumor ROI Segmentation

Module: src/segmentation.py

The extract_roi_otsu() function implements a morphology-based region-of-interest extractor for overlay visualization. A full Lightweight U-Net is also implemented for optional future pixel-precise segmentation.

Segmentation Steps

  1. Brain Isolation — Separates brain tissue from the black MRI background.
  2. Adaptive Intensity Thresholding — Targets hyper-intense tumor regions dynamically.
  3. Morphological Operations — Erosion and dilation clean the binary mask.
  4. Connected-Component Analysis — Filters components by area, eccentricity, and position to select the most plausible tumor candidate.
  5. Bounding Box Extraction — Computes (x, y, w, h) ROI bounding box.
  6. Coverage Rejection — Masks covering >85% of the image are rejected as spurious detections.

4.4 Stage 5 — Deep Feature Extraction (EfficientNetB0)

Module: src/feature_extractor.py

EfficientNetB0 pretrained on ImageNet-1K is used as the deep feature backbone. A two-phase fine-tuning strategy is applied:

Phase 1 – Freeze

  • All model parameters frozen
  • Preserves pretrained representations
  • Prevents catastrophic forgetting

Phase 2 – Fine-tune

  • Last 20 layers unfrozen
  • Classifier head: Linear(1280 → 4)
  • Adam optimizer, lr = 1e-4
  • CrossEntropyLoss, 3–10 epochs

After fine-tuning, the classification head is removed. The backbone's Global Average Pooling (GAP) layer produces a 1,280-dimensional feature vector per MRI image. Feature arrays are saved as NumPy .npy files.

feature_extractor = nn.Sequential(
    *list(model.children())[:-1],
    nn.AdaptiveAvgPool2d((1, 1))    # -> (B, 1280, 1, 1)
)
features = torch.flatten(features, 1)  # -> (B, 1280)

4.5 Stage 6 — Genetic Algorithm Feature Selection

Module: src/optimization/ga_selector.py & src/optimization/fitness.py

A custom Binary Genetic Algorithm (GA) solves the NP-hard combinatorial feature subset selection problem. Each chromosome is a 1,280-bit binary vector where 1 = select, 0 = discard.

GA Configuration

ParameterValueDescription
Population Size30Number of chromosomes per generation
Generations40Number of evolutionary iterations
Crossover Rate0.80Probability of uniform crossover
Mutation Rate0.05Per-bit flip probability
Tournament Size3Selection pressure
Alpha Penalty (α)0.01Fitness penalty per feature ratio
Random Seed42Reproducibility
Fitness Function:
Fitness(chromosome) = Validation_Accuracy − α × (Selected_Features / Total_Features)
This penalises large feature subsets, driving the GA to find the most compact yet accurate feature set.

Evolutionary Operators

  • Initialization: Random binary population (Bernoulli p=0.5 per bit).
  • Selection: Tournament selection (size=3) — three random individuals compete; the fittest wins.
  • Crossover: Uniform crossover — each bit independently inherited from either parent with equal probability.
  • Mutation: Bit-flip mutation (XOR with random mask) at rate 0.05 per bit.
  • Elitism: Global best chromosome is always carried forward unchanged.
  • Parallelism: Fitness evaluation parallelised across all CPU cores via joblib.Parallel.

4.6 Stage 7 — Classifier Training & Hyperparameter Tuning

Four classifiers are trained on the 630 GA-selected features using 5-fold Stratified Cross-Validation with GridSearchCV.

SVM Probability Calibration: The SVM uses Platt scaling (CalibratedClassifierCV) to produce reliable class probability estimates, enabling ROC-AUC computation and probability charts in the web app.

4.7 Stage 8 — Model Evaluation & Metrics

Module: src/evaluate.py

All four classifiers are evaluated on the held-out test set (1,080 MRI scans). Computed metrics:

  • Accuracy — Percentage of correctly classified samples.
  • Precision (Macro) — Average precision across all 4 classes, equally weighted.
  • Recall / Sensitivity (Macro) — Ability to correctly detect each tumor type.
  • Specificity (Macro) — True Negative Rate: TN / (TN + FP), macro-averaged.
  • F1-Score (Macro) — Harmonic mean of Precision and Recall.
  • ROC-AUC (One-vs-Rest) — Area under ROC curve per class vs. rest, macro-averaged.

All metrics and plots are saved to reports/metrics.json and reports/figures/.

Champion Classifier: The SVM with RBF Kernel achieved the highest test accuracy of 92.59%, specificity of 97.53%, and ROC-AUC of 0.9802 — using just 630 out of 1,280 features (50.78% dimensionality reduction via GA). The GA-driven feature selection not only reduced computational cost but actively improved classifier discriminability by removing noisy features.

Key Observations

  • All four classifiers achieve ROC-AUC > 0.97, confirming EfficientNetB0 captures highly discriminative representations.
  • The SVM's RBF kernel effectively handles non-linear separability of the 630-D feature manifold.
  • XGBoost and Softmax perform comparably (~88.5–89%), indicating feature quality is the primary driver.
  • The GA's 50.78% feature reduction decreases inference latency by ~50% with a net accuracy gain over using all 1,280 features.

8. Installation & Quick Start

Requirements

  • Python 3.9 – 3.12 (PyTorch does not support Python 3.13+)
  • ~5 GB free disk space (dataset + model weights)
  • Kaggle API token (~/.kaggle/kaggle.json)
  • CUDA GPU (optional — CPU inference is fully supported)

1. Create a Python 3.12 Virtual Environment

py -3.12 -m venv venv
.\venv\Scripts\activate          # Windows PowerShell

2. Install PyTorch (CPU build)

pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

3. Install All Remaining Dependencies

pip install streamlit opencv-python-headless pillow scikit-learn scikit-image \
            scipy xgboost numpy pandas matplotlib seaborn joblib tqdm python-dotenv

4. Download the Dataset

python src/dataset_setup.py

5. Run the Full Pipeline

python run_all.py

6. Launch the Web Application

python -m streamlit run app/streamlit_app.py
# Open: http://localhost:8501
Note on GPU: CUDA availability is detected automatically via torch.cuda.is_available() in config.py. GPU training significantly speeds up EfficientNetB0 fine-tuning (Stage 5).
